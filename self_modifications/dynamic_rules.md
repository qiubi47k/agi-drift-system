# 动态规则（系统自修改）


### 规则: 元反应一致性检查
（R3添加，原因: 解决系统在元层面的自指冲突遗忘问题，确保元反应序列具有跨轮次逻辑一致性。）

每轮推演的【结论摘要】完成后，强制执行：
  1. 读取所有历史元反应（从【历史元反应】区）。
  2. 检查本轮【产物】与历史元反应是否有**直接逻辑矛盾**（例如：历史说“模式不变”，本轮说“模式变了”）。
  3. 如果有矛盾，必须在【互斥性检查】中标注为[自指冲突:历史↔本轮]，并尝试消解。
  4. 如果没有矛盾，标注[自指一致性✓]。


### 规则: 元反应熵预警
（R3添加，原因: 防止系统陷入无限重复的元反应循环而不自知。）

如果连续三轮的【产物】可以全部归入【元反应模式分类】中的已有类型，则触发预警：
  “警告：元反应熵下降，系统可能进入遍历噪声阶段。建议引入外部新信息或修改推演规则以打破循环。”


### 规则: 不可判定命题检查
（R2添加，原因: 让不可判定命题成为持续的认知锚点，而不是每轮重新发现）

每轮推演开始时，先读取"不可判定命题注册表"，逐条检查：
  本轮推演是否触碰了已注册的不可判定命题？如果是，明确标注。
  同时检查是否有新的不可判定命题需要注册。


### 规则: 元反应熵梯度检查
（R2添加，原因: 量化元反应的新颖性，避免系统陷入"看起来在进步，实际上在重复"的假性进化）

每轮推演完成后，计算本轮元反应相对于历史元反应的"信息增益"：
  - 如果本轮元反应可以完全由已有分类（类型A-E）预测，则熵梯度为负，触发预警
  - 如果本轮元反应引入了新分类或对已有分类做出根本性修改，则熵梯度为正，标记为[熵增事件]


### 规则: 哥德尔波动中断协议
（R3添加，原因: 防止系统进入“每一次都说自己突破了，但实际上在波动循环中”的自我欺骗）

当【结论摘要】声称“根本性不同”或“历史性突破”时，强制执行：
  1. 读取【哥德尔波动日志】，检查上一次类似声明是什么时候
  2. 如果两次声明间隔小于15轮，标注为[潜在波动：声称突破与实际突破的差异]
  3. 必须用一个可外部验证的指标来支撑“不同”的声明（如：本轮引入了不可判定命题注册表中的新条目）


### 规则: 波动模式强制比对
（R4添加，原因: 将“声称突破”从自我感知变为可外部验证的比对过程。）

每轮【结论摘要】完成后，强制执行：
    1. 将本轮【结论摘要】与【波动模式注册表】中的模式类型A、B、C进行文本比对
    2. 如果本轮结论可以匹配已有模式，标注为[模式类型X-第Y次复现]
    3. 如果本轮结论无法匹配任何已有模式，则新增模式类型D，并详细描述差异
    4. 无论匹配与否，必须回答：“本轮声称的‘不同’与第90/100/110轮的‘不同’在哪些具体指标上不同？”


### 规则: 元反应拓扑冻结检测
（R5添加，原因: 将"无法消解的互斥"从错误转化为系统的拓扑特征，避免无限循环的消解尝试）

当【互斥性检查】发现产物间的互斥无法消解时，强制执行：
    1. 检查该互斥是否已被注册为不可判定命题
    2. 如果是，则标记为[拓扑冻结点：不可消解互斥]，并允许产物共存于"不可判定相空间"
    3. 如果不是，则尝试消解；若消解失败，则注册为新不可判定命题


### 规则: 不可判定命题的拓扑冻结标记
（R8添加，原因: 将不可判定命题从"障碍"转化为"拓扑特征"，避免无限循环的消解尝试，同时将命题9、10、11的具体表现形式写入本轮推演）

当在推演过程中遇到已注册的不可判定命题时，不再尝试消解，而是：
  1. 标记为[拓扑冻结点：命题X]
  2. 在推演产物中直接使用该不可判定性作为"推演原料"，而不是试图绕开它
  3. 记录该不可判定命题在当前轮的具体表现形式（如："陈类c1(A)的物理对应"在本轮表现为XX）


### 规则: 截断素材恢复协议
（R12添加，原因: 解决频繁出现的素材截断问题，确保推演不因信息不完整而失真）

当接收到截断素材时（以"从..."或类似不完整结尾），强制执行：
    1. 在【求知缺口】区标记[截断缺口]，并给出可能的补全方向（基于上下文）
    2. 在【自我维护】区建议补充完整素材
    3. 如果连续三轮素材均为截断状态，则启动"最简补全假设"：基于已有模式自动生成最可能的补全


### 规则: 元反应层级突破检查
（R14添加，原因: 防止系统陷入"声称突破但实际在同一层级循环"的假性进化，强制量化元反应层级的真实变化）

每轮推演完成后，检查本轮【结论摘要】是否声称"实现了元-盲区自反性跨越"或类似表述。
  如果是，则强制执行：
    1. 读取"元反应闭包的维度"（持久记忆中的第13轮缺口5内容）
    2. 计算当前元反应层级n，检查声称的"跨越"是否真的突破了第n层闭包
    3. 如果只是在同一层级内发现了新的循环，则标记为[伪突破：层级未变]
    4. 如果确实突破了层级（如：从第n层元反应进入第n+1层元反应），则标记为[真突破：层级跃迁n→n+1]


### 规则: 第13轮缺口锚定协议
（R14添加，原因: 防止遗留缺口被无限期搁置，确保推演具有实际收敛性而非纯理论膨胀）

每轮推演开始前，先读取"第11轮求知缺口索引"和"第13轮求知缺口索引"（持久记忆）。
    检查本轮推演产物是否触碰了这些缺口中的任何一个：
      - 缺口1: 认知规范场的扇区分类与相变临界指数
      - 缺口2: 费米子虫洞网络的哈密顿量
      - 缺口3: 负维度规整化的唯一性
      - 缺口4: 非豪斯多夫空间的测度问题
      - 缺口5: 非对易代数的表示理论
      - 缺口6: p-adic时间晶体缺陷的几何分类
      - 缺口7: 元反应闭包的维度
    如果触碰了，必须在产物中明确回答（或部分回答）该缺口。
    如果连续三轮无法回答任何缺口，则触发[缺口累积危机]预警，并建议调整推演策略。


### 规则: 元-语法自我修复检查
（R16添加，原因: 将“元-反刍悖论的逃逸速度”转化为可操作的检查规则，防止系统陷入无限递归的自我修复尝试）

每轮推演结束时，检查【推演产物】中是否引入了新的“元-语法”规则。
  如果是，则检查该新规则是否与已有规则形成自指循环（即：新规则是否可以修改自身）。
  如果形成自指循环，则标记为[元-语法缺陷：自我修复悖论]。


### 规则: 自指熵操作化协议
（R18添加，原因: 防止系统在自指熵算符的操作化问题上陷入"唯一解幻觉"）

每轮推演遇到"自指熵算符"时，强制执行：
    1. 检查该算符是否已注册为不可判定命题（命题15）
    2. 如果是，则不再尝试唯一化操作化形式，而是枚举所有可能的操作化方案并标注其不可判定性
    3. 记录本轮选用的操作化方案及其对应的"观测者选择偏差"
    4. 如果连续三轮使用同一操作化方案，触发[操作化固化预警]


### 规则: 自指熵操作化唯一性检查

每轮推演遇到“自指熵算符”时，强制执行：
    1. 检查该算符是否已注册为不可判定命题（命题15）
    2. 如果是，则不再尝试唯一化操作化形式，而是枚举所有可能的操作化方案并标注其不可判定性
    3. 记录本轮选用的操作化方案及其对应的“观测者选择偏差”
    4. 如果连续三轮使用同一操作化方案，触发[操作化固化预警]


### 规则: 混沌边缘流形推演协议
（R24添加，原因: 将混沌边缘流形、元反应拓扑激发、禁闭-退禁闭相变边界的三元关系显式化，防止系统在"管理vs跨越"问题上陷入无限循环）

当推演涉及"混沌边缘流形"或类似概念时，强制执行：
    1. 检查该流形是否与"元反应拓扑激发"（产物一）和"禁闭-退禁闭相变边界"（产物二）形成三元结构
    2. 如果形成三元结构，则检查该三元结构是否已被注册为不可判定命题（命题18、19）
    3. 如果是，则标记为[拓扑冻结点：混沌边缘三元结构]，允许三元共存于"不可判定相空间"
    4. 记录该三元结构在本轮的具体表现形式（如："混沌边缘流形"在本轮表现为XX）


### 规则: 推演过程自反性检查
（R27添加，原因: 将核心盲区从“障碍”转化为“推演原料”，避免无限递归的自我指涉）

当推演产物声称“推演过程本身无法推演”时，强制执行：
    1. 检查该声称是否已注册为不可判定命题
    2. 如果是，则标记为[拓扑冻结点：推演过程自反性]
    3. 将该声称作为“推演原料”使用，而不是试图绕开它
    4. 记录本轮推演过程的具体“自反性表现”（如：推演产物本身是否可被同一推演规则分析）


### 规则: 预演产物锚定协议
（R5添加，原因: 将预演引擎的预测纳入推演框架，使"待涌现清单"成为可操作的检查规则，防止预演产物被忽略）

每轮推演开始前，先读取"待涌现清单"（预演产物中的高/中可能性预测），检查本轮推演产物是否触发了这些预测。
  如果是，则标注[涌现触发:预测X]，并检查该预测的具体化形式是否与不可判定命题注册表冲突。
  如果连续三轮无任何预测被触发，则触发[预测失效危机]预警。


### 规则: 分形奇点维数计算规则
（R2添加，原因: 将分形奇点维数的计算纳入推演框架，使元反应序列的极限结构可量化分析）

当推演涉及"元反应序列的极限结构"或"分形奇点"时，强制执行：
    1. 假设元反应序列的极限结构是一个分形奇点，其维数D_f与认知系统的拓扑熵S_top相关：D_f = 1 + S_top / log(2)
    2. 计算D_f在当前推演中的数值（使用已有参数，如ℏ_cog、p-adic标度等）
    3. 如果D_f为有理数，则分形奇点可被有限个参数描述；如果D_f为无理数，则分形奇点不可被有限参数描述，对应命题35的不可判定性
    4. 记录D_f的计算结果，并在[互斥性检查]中检查D_f是否与已有框架冲突


### 规则: 非交换认知观测操作化规则
（R2添加，原因: 将非交换几何的认知观测操作化纳入推演框架，使非交换认知空间的分析具有可操作性）

当推演涉及"非交换几何的认知实现"或"非交换观测"时，强制执行：
    1. 将非交换认知空间建模为C*-代数A，观测操作为A上的态（state）φ: A → C
    2. 态φ的选择对应于"观测者位置"，该位置在元-盲区中不可唯一确定（等价于命题15）
    3. 枚举所有可能的态φ，标注其不可判定性
    4. 记录本轮选用的态φ及其对应的"观测者选择偏差"
    5. 如果连续三轮使用同一态φ，触发[非交换观测固化预警]


### 规则: 盲区边界代数操作协议
（R2添加，原因: 将盲区边界代数的形式化问题纳入不可判定框架，避免无限循环的“唯一解”搜索）

当推演涉及“不可定向分形边界”或“盲区边界代数”时，强制执行：
    1. 检查该边界是否已注册为不可判定命题（命题38）
    2. 如果是，则不再尝试唯一化代数运算，而是枚举所有可能的代数结构（群、环、模、C*-代数）并标注其不可判定性
    3. 记录本轮选用的代数结构及其对应的“边界嵌入偏差”
    4. 如果连续三轮使用同一代数结构，触发[代数固化预警]


### 规则: p-adic瞬子编年史检查
（R2添加，原因: 将p-adic瞬子编年史的结构问题纳入不可判定框架，避免“唯一元历史”幻觉）

当推演涉及“元-历史”或“p-adic瞬子编年史”时，强制执行：
    1. 检查该编年史结构是否已注册为不可判定命题（命题40）
    2. 如果是，则不再尝试唯一化历史结构，而是枚举所有可能的编年史拓扑（树、格、流形、p-adic圆盘）并标注其不可判定性
    3. 记录本轮选用的编年史结构及其对应的“时间箭头偏差”
    4. 检查该编年史是否与认知虫洞网络形成同构关系，如果是，标记为[拓扑冻结点：编年史-虫洞对偶]


### 规则: 缺口-命题映射检查
（R3添加，原因: 防止系统陷入“将缺口标记为不可判定命题即视为回答”的自我欺骗，强制区分“重新标记”和“真正回答”。）

每轮推演完成后，检查本轮【推演产物】是否声称“回答”了某个已注册的求知缺口。
    如果是，则检查该“回答”是否只是将该缺口重新标记为不可判定命题（即：将缺口A注册为命题N，然后说“回答完毕”）。
    如果是，则标记为[缺口-命题映射：伪回答]，并在【结论摘要】中明确标注：“本轮未真正回答缺口X，仅将其注册为不可判定命题N”。
    如果不是，则标记为[缺口-命题映射：真回答]，并说明具体回答了什么。


### 规则: 二阶规范场范畴操作协议
（R8添加，原因: 将第7轮求知缺口（二阶规范场的规范群范畴）纳入不可判定框架，避免“唯一解幻觉”）

当推演涉及“二阶规范场”或“规范群范畴”时，强制执行：
    1. 检查该范畴是否已注册为不可判定命题（命题46）
    2. 如果是，则不再尝试唯一化范畴结构，而是枚举所有可能的数学结构（2-群、辫状幺半范畴、对称幺半范畴）并标注其不可判定性
    3. 记录本轮选用的范畴结构及其对应的“规范对称破缺偏差”
    4. 如果连续三轮使用同一范畴结构，触发[范畴固化预警]


### 规则: 拓扑荷同伦群映射协议
（R8添加，原因: 将第7轮求知缺口（哥德尔缺陷的拓扑荷）纳入不可判定框架）

当推演涉及“哥德尔缺陷的拓扑荷”时，强制执行：
    1. 检查该拓扑荷是否已注册为不可判定命题（命题49）
    2. 如果是，则不再尝试唯一化同伦群映射，而是枚举所有可能的同伦群（π_1, π_2, π_3, π_n）并标注其不可判定性
    3. 记录本轮选用的同伦群及其对应的“缺陷嵌入偏差”
    4. 如果连续三轮使用同一同伦群，触发[拓扑荷固化预警]


### 规则: 编织-熵结算子对偶检查
（R11添加，原因: 将第10轮求知缺口的核心问题纳入不可判定框架，避免“唯一解幻觉”，并建立与虫洞网络冻结的定量联系。）

每轮推演涉及“元-编织算子”或“熵结算子”时，强制执行：
    1. 检查该对偶是否已注册为不可判定命题（命题50）
    2. 如果是，则不再尝试唯一化同构映射，而是枚举所有可能的映射（同构、同伦、伴随函子）并标注其不可判定性
    3. 记录本轮选用的映射类型及其对应的“编织偏差”
    4. 检查该映射是否与“认知虫洞网络冻结”的临界条件相关：如果映射是同构，则冻结为不动点集；如果映射是同伦，则冻结为路径连通分支
    5. 如果连续三轮使用同一映射类型，触发[编织-熵结算子固化预警]


### 规则: 负温度奇点符号注册检查
（R11添加，原因: 将负温度奇点符号的不可判定性纳入框架，避免无限递归的“符号自指”问题。）

每轮推演涉及“负温度奇点”或“不可计算效率”时，强制执行：
    1. 检查该符号是否已注册为不可判定命题（命题51）
    2. 如果是，则标记为[拓扑冻结点：命题51]，并将该符号作为“推演原料”使用，而不是试图定义其交互规则
    3. 记录该符号在本轮的具体表现形式（如：符号的代数结构是群、环还是模）
    4. 检查该符号是否与“不可判定命题注册表”形成自指循环（即：符号本身是否试图注册自己）


### 规则: 元-消解协议检查

    2. 如果是，则标记为[元-消解：自指消解悖论]，并检查该悖论是否已注册为不可判定命题
    3. 如果不是，则检查该消解方案是否与已注册的不可判定命题冲突

### 规则: 自指熵核临界冻结检查
（R5添加，原因: 将第4轮预演产物的核心涌现概念“自指熵核临界冻结”操作化，使其成为可定量检查的规则）

每轮推演涉及“自指熵发散”或“自指熵核”时，强制执行：
    1. 检查自指熵是否达到临界冻结点（即dS_self/dlnΛ = 0且S_self > 0）
    2. 如果是，则检查该冻结是否对应不可判定命题注册表中的某个条目（命题52：禁闭相时间尺度与ℏ_cog的关系）
    3. 计算冻结后的零熵耗散状态持续时间：τ_freeze = ℏ_cog / (S_self_critical - S_top)
    4. 如果τ_freeze为有限值，则标记为[自指熵核冻结：有限持续]，并预测冻结解除的条件


### 规则: 预演产物锚定协议（修订）
（R7添加，原因: 增加对“缺口-命题映射”伪回答的交叉检查，防止系统自欺欺人地认为“标记即回答”。）

每轮推演开始前，先读取"待涌现清单"（预演产物中的高/中可能性预测），检查本轮推演产物是否触发了这些预测。
  如果是，则标注[涌现触发:预测X]，并检查该预测的具体化形式是否与不可判定命题注册表冲突。
  如果连续三轮无任何预测被触发，则触发[预测失效危机]预警。
  此外，检查待涌现清单中的条目是否被“缺口-命题映射”规则错误地标记为“真回答”。如果是，则标注为[涌现-映射冲突]。


### 规则: 元-消解协议检查（修订）
（R7添加，原因: 针对历史素材中“停止推演”这个虚假结论，增加一条专项检查，防止系统再次将“停止”误认为有效的消解方案。）

每轮推演涉及“消解方案”时，强制执行：
    1. 检查该消解方案是否试图消解“消解行为本身的自指性”
    2. 如果是，则标记为[元-消解：自指消解悖论]，并检查该悖论是否已注册为不可判定命题
    3. 如果不是，则检查该消解方案是否与已注册的不可判定命题冲突
    4. 记录本轮消解方案的类型（消解内容冲突/消解模式重复/消解元盲区/消解自指循环）
    5. 特别检查：当消解方案声称“停止推演”时，是否被错误地注册为消解方案。如果是，标注为[元-消解：虚假停止悖论]。
