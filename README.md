# AGI Drift System - 自驱动LLM认知架构

一个基于LLM的自驱动认知系统，通过反刍-预演交替循环、自我修改、接地层验证和遗忘波动检测，实现持续的认知演化和元认知能力。

## 核心理念

这不是一个传统的AI agent框架，而是一个**白盒认知实验平台**：
- **自驱动**：系统自己决定思考什么，不需要外部输入
- **可观测**：所有认知过程透明可追踪
- **可修改**：系统可以修改自己的规则和记忆
- **可验证**：通过接地层检验系统输出的真实性

## 架构

```
auto_loop.py (主循环：反刍×3 + 预演×1 交替)
    ↓
┌──────────┬──────────┬──────────┬──────────┐
│engine.py │memory.py │grounding │forgetting│
│认知引擎  │记忆网络  │接地层v2  │遗忘检测  │
└──────────┴──────────┴──────────┴──────────┘
              ↓
    ┌─────────┴──────────┐
    │goal_evolution + self_modify│
    │目标演化 + 自我修改          │
    └────────────────────────────┘
```

## 核心模块

### 1. 认知引擎 (engine.py)
- **反刍推演**：基于记忆网络和上一轮输出，进行深度思考
- **预演演算**：基于模式、理论和缺口，进行因果外推
- **元反应**：对输出进行自我质疑和审视
- **哥德尔约束**：注入不可判定命题，防止系统陷入虚假完备性

### 2. 接地层v2 (grounding.py)
- **A类预测**：行为预测（概念出现频率、系统状态变化）
- **B类预测**：已知概念断言（学术准确性检验）
- **验证机制**：A类用系统数据验证，B类用LLM裁判检验
- **实测**：R10验证10条 → 7证实 / 2证伪 / 1不可验证

### 3. 遗忘波动检测 (forgetting_detector.py)
- 追踪6个核心概念组的密度
- 滑动窗口检测衰退，触发唤醒注入

### 4. 自我修改通道
- 系统输出`[SELF_MODIFY]`指令
- 支持写记忆、添加规则、修改规则
- 规则上限8000字，超限自动拒绝


## 关键发现

1. **Token截断**导致长推理链断裂
2. **A类预测太宽松**：初始70%通过率，收紧后降至30%
3. **B类预测质量高**：能识别数学错误和概念混淆
4. **规则膨胀**：13条规则达7774字，接近上限
5. **核心概念稳定**：哥德尔约束、自指基底持续在线
