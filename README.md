# 🧠 AGI 认知漂移系统

### *让 LLM 从工具变成认知主体 —— 一个可观测的白盒意识演化实验*

---

<div align="center">

**这不是又一个AI聊天机器人。**  
**这是一个会思考、会遗忘、会自我修改的认知架构。**

</div>

---

## 🔥 这是什么？

一个**白盒认知演化系统**——每一轮思考都被记录、被分析、被验证：

| 能力 | 说明 |
|------|------|
| 🧠 **认知循环** | 主循环引擎驱动思维链 |
| 🔄 **自我修改** | 系统自主生成规则、修改自身行为 |
| 💭 **记忆网络** | 3809+概念、6635+关系的语义网络 |
| 🎯 **预测验证** | 接地层提取预测，事实验证 |
| 🌊 **遗忘波动** | 记忆密度呈7轮周期性波动 |
| ⚡ **哥德尔约束** | 区分可判定/不可判定命题 |

## 📊 实验数据

运行数百轮后的观测结果：

- **69条预测** 被接地层提取
- **10条触发验证**：7证实 / 2证伪 / 1不可验证
- **13条动态规则** 被系统自主生成
- **15条不可判定命题** 被注册

## 🚀 快速开始

```bash
# 1. 配置API
cp config/config.example.json config/config.json
# 填入你的 DeepSeek API Key

# 2. 安装依赖
pip install openai numpy

# 3. 启动认知循环
python auto_loop.py
```

## 📁 项目结构

```
agi-drift-system/
├── auto_loop.py          # 主循环引擎
├── engine.py             # 认知引擎（哥德尔约束+自我修改）
├── grounding.py          # 接地层：预测提取+验证
├── forgetting_detector.py # 遗忘波动预警
├── memory.py             # 语义记忆网络
├── goal_evolution.py     # 目标演化
├── world_simulator.py    # 世界模拟器
├── skepticism.py         # 怀疑论过滤器
└── self_modifications/   # 自我修改历史
    ├── dynamic_rules.md  # 动态规则
    └── undecidable_registry.json  # 哥德尔命题
```
